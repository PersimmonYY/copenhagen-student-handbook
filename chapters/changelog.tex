\section{更新日志}

\subsection*{2026.11（2026年9月3日）}
\begin{itemize}
  \item 将当前版本标记为 CSSA-Copenhagen 内部审核稿，暂勿向审核范围之外转发；项目不属于开源，也未授权开放内容许可。
  \item 根据小红书丹麦留学相关内容中反复出现的实际问题，使用官方来源重新撰写交通罚单申诉、Pant 退瓶押金、MitID User ID 恢复和永久离丹倒排时间线。
  \item 新增 Sygeforsikringen ``danmark'' 会员资格提示、北欧冬季心理健康准备、维生素 D 官方建议及 Studenterrådgivningen 支持入口。
  \item 扩充工会与 A-kasse 的职业服务比较，保留“服务不能保证获得面试或工作”的边界，并继续以中国籍非欧盟学生的工作许可和福利限制为前提。
  \item 建立社交平台内容吸收与版权规范：社交内容用于发现问题，事实以官方来源复核，正文独立撰写；未获授权不复制原文、截图、图片或原创表格。
\end{itemize}

\subsection*{2026.10（2026年9月2日）}
\begin{itemize}
  \item 完成第二轮全书审校并建立独立审校报告；更新驻丹麦使馆领事保护电话，删除失效的学联域名，修正 Netto+、社交活动和反诈章节中的无依据或绝对化表述。
  \item 将签证在线流程改为不依赖固定按钮和登录界面的稳定写法；新增学生居留公共福利风险提示，统一哥本哈根黄卡寄送与查询口径。
  \item 重写丹麦语选校与班型说明，删除容易过期的固定课表；补充平台接单、自雇、志愿服务及毕业后无工时限制工作许可的判断路径。
  \item 扩充行前倒排时间线、入境材料、海关检疫、设备衣物和抵丹 72 小时清单；新增手机/eSIM/宽带、中国号码保号、欧盟漫游和保险地图。
  \item 补充租期内水电暖、表计、霉菌虫害、房屋规则和保险提示；将原空白 FAQ 与微信群文件改为可操作的常见问题和官方新生群安全章节。
  \item 新增来源维护台账，记录关键金额、期限、电话、资格和下一次复核节点。
\end{itemize}

\subsection*{2026.9（2026年9月2日）}
\begin{itemize}
  \item 合并完成原 2026.5--2026.9 五个工作包：重写医疗与紧急情况，补充财务数字生活、实习就业和在丹身份生命周期，并更新交通、自行车、购物、社交娱乐等城市生活内容。
  \item 所有新增和修改内容继续以从中国赴丹麦的非欧盟高等教育学生为默认读者；对 CPR、黄卡、学生居留、工作许可和税务身份作出明确区分。
  \item 建立腾讯文档共建批注台账，逐条处理 14 组评论；有官方来源的事实写入正文，窗口个案和生活经验仅以匿名“学长学姐碎碎念”形式保留。
  \item 新增“学长学姐碎碎念”完整免责声明及各栏短提示；更新共建入口为腾讯文档，删除固定航司、健身、影音等容易过时的价格与结果承诺。
  \item 按 2026 年官方页面核验 SIRI 学生工作/实习/续签/离境规则、法罗群岛和格陵兰短期入境、MitID 备用认证器、税卡、1813、黄卡及从非欧盟地区带药新规。
\end{itemize}

\subsection*{2026.4（2026年8月12日）}
\begin{itemize}
  \item 全面重构“住房与租房避坑”章节，以中国非欧盟学生远程找房、尚无 CPR、MitID 和丹麦账户等实际场景为默认前提。
  \item 新增全过程流程表、房源类型比较、出租权和 CPR 地址核验、官方标准合同阅读、押金与预付租金拆分、诈骗风险表、入住 14 天取证、退租验房和争议处理路径。
  \item 新增四份英文沟通模板与全过程勾选表，移除容易过时的固定宿舍价格和未经核验的个别宿舍评价，并加入 KU、DTU、CBS、ITU、RUC 官方住房入口。
  \item 将住房章节与抵丹时间线、银行及反诈章节交叉引用；关键期限和权利义务按丹麦社会与住房部、Life in Denmark 及哥本哈根市政府页面核验。
\end{itemize}

\subsection*{2026.3（2026年8月12日）}
\begin{itemize}
  \item 新增“抵丹后 30 天落地时间线”，按住址、CPR、黄卡、MitID、Digital Post、银行账户、NemKonto、税卡和居留卡的依赖关系安排办理顺序。
  \item 针对从中国来丹的非欧盟学生补充中国护照无法通过手机扫描、邮寄卡件延迟、无长期住址、银行补件和搬家改址等常见卡点。
  \item 将建议时间、通常等待时间和明确申报期限分开表述，并附 International House Copenhagen、Life in Denmark、MitID、NemKonto 与 SKAT 官方入口。
\end{itemize}

\subsection*{2026.2（2026年8月12日）}
\begin{itemize}
  \item 明确本手册默认面向从中国赴丹麦、以非欧盟身份申请或持有学生居留许可的留学生；欧盟、欧洲经济区、瑞士及北欧身份不默认适用。
  \item 新增“学业与校园生活”章节，补充积极在读与居留许可的关系、ECTS 与课程注册、考试和评分、申诉、学术诚信与生成式 AI，以及休学、转学、延期和退学的处理思路。
  \item 对容易随学校或课程变化的规则统一增加核验提醒，避免把单一院校经验写成全国通则。
\end{itemize}

\subsection*{2026.1（2026年8月12日）}
\begin{itemize}
  \item 将版本更新为 2026--2027 学年版，并改用人工维护的发布日期和政策核验日期。
  \item 第一轮纠错：更新学生居留申请费用、资金标准、VFS 办理说明，以及抵丹后的 CPR、黄卡、居留卡、MitID 和地址登记流程。
  \item 更新公共交通票务：移除已经停用的实体 Rejsekort 操作说明，加入 Rejsekort App、Rejsebillet、Basiskort，并更新首都轻轨开放进度。
  \item 纠正 NemKonto、公共医疗和药品购买说明；更新学生工作许可、毕业求职期及丹麦语 klippekort 规则。
  \item 更新丹麦警方和中国驻丹麦大使馆紧急联系方式，修复失效链接、LaTeX 选项冲突及一批明显文字错误。
\end{itemize}
