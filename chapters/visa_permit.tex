\section{签证办理}

\subsection{阅读须知}

本章节整理的是非欧盟学生申请丹麦学生居留许可及抵丹后登记的常见流程。大家口语中常说的“学生签”，正式名称为基于学习目的的居留许可（residence permit for study）。政策、费用和材料可能调整，提交前请\textbf{务必}以 SIRI、丹麦外交部及中国区 VFS Global 的实时页面为准：

\begin{itemize}[label=•,leftmargin=2em,itemsep=2pt]
  \item SIRI 高等教育学生居留规则：\url{https://www.nyidanmark.dk/en-GB/You-want-to-apply/Study/Higher-education}
  \item SIRI 联系方式：\url{https://www.nyidanmark.dk/en-GB/Contact-us/Contact-SIRI}
  \item 丹麦驻华签证申请中心：\url{https://visa.vfsglobal.com/chn/en/dnk/}


\end{itemize}


若想加入学联 2026 年丹麦留学新生群，可在学联微信公众号【哥本哈根 CSSA】或小红书【哥本哈根学联（CSSA）】后台私信获取入群方式。群内经验不能替代官方要求。

\paragraph{什么是 ST1 表格？}

ST1 是丹麦政府为学生居留许可设计的官方表格，分为两部分：\textbf{Part 2} 由学校填写，\textbf{Part 1} 由学生完成。仅在学生满足全部入学条件后，学校才会填写 ST1；应届生须拿到双证后尽快换 \emph{unconditional offer}，以便早日获取 ST1 并递签。

\begin{itemize}[label=•,leftmargin=2em,itemsep=2pt]
  \item 2026 年 SIRI 学习类案件处理费为 3 060 DKK；不要与驻外使团办理费或 VFS 服务费混淆。
  \item 缴费后请务必截图／下载成功回执。
  \item 签证审核时长不定，建议学校发完 ST1 后尽快提交并录生物信息。
\end{itemize}

\begin{grayleftbox}{\textbf{学长学姐碎碎念}}
  \begin{itemize}
    \item 2024 年申请者曾反馈部分材料需要彩印、护照需要完整复印。此处仅保留为历史经验；2026 年请以 VFS 页面及现场通知为准，不要仅按旧清单准备。
    \item 扫描件应清晰、完整、无水印，页面方向和尺寸便于审核；提交前逐项对照在线清单。
  \end{itemize}
\end{grayleftbox}


\subsubsection{中国大陆签证申请中心}

丹麦在中国大陆的申请中心数量、地址、开放时间和递交方式可能调整。请通过 VFS Global 丹麦中国区网站的 \textbf{Find a centre} 查询实时信息：\url{https://visa.vfsglobal.com/chn/en/dnk/}。截至本版核验时，居留和工作许可申请通常无需提前预约，但出发前仍须检查所选中心的最新规则。



\begin{grayleftbox}{\textbf{学长学姐碎碎念}}
\begin{itemize}
\item 不同申请人的处理时间差异很大，不要根据某个城市的个案推断下签速度。
\item 如毕业证下发较晚，可尽早向学校确认换取 unconditional offer 和启动 ST1 的材料要求。
  \end{itemize}
\end{grayleftbox}


\section{居留许可 \& 黄卡申请}

新生抵丹并落实真实住址后，应尽快完成 CPR 登记和数字服务设置。International House 可办理 CPR、黄卡登记和 MitID 等市民服务，但\textbf{居留卡（粉卡）由 SIRI 或丹麦移民局制发}，并不是在 International House 当场办理。

% --- Comment Box -------------------------------------------------
\begin{grayleftbox}{\textbf{小贴士： }}
  \begin{itemize}
    \item 拿到 CPR 并激活 MitID 后，记得邮件告知学校，以便在学校系统里更新CPR；
    \item 搬家后应在 5 日内申报真实地址；未按时申报可能受罚。离开丹麦时也应按实际离境日期注销登记。
    \item \textit{Digital Post} App 可查看政府来信；报税、交通罚款、青年卡政策变动等都在此处理。
    \item \textit{Sundhedskortet} App 可获得电子黄卡。
    \item 申根区旅行请随身携带护照 + 粉卡。
  \end{itemize}
\end{grayleftbox}
