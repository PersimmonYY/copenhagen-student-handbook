\section{丹麦语}

\subsection{丹麦语课程介绍} \label{sec:danish}
\crefname{subsection}{节}{节}  % 输出“5.1 节”  

\subsubsection{官方丹麦语教育（Danskuddannelse）概览}
年满 18 周岁的外国居民如符合《成人外国人丹麦语教育法》的条件，可由居住地市政转介（henvisning）参加官方丹麦语教育（Danskuddannelse）。课程由获批准的语言学校开设，最终可参加全国性语言考试。学生等通常归入 S-kursist，其学习权利受市政转介、五年有效期和 klippekort（模块券）规则共同约束；并非仅凭“持有合法居留”即可无限期免费就读。

\subsubsection{课程与等级设置}
官方课程分为 Danskuddannelse 1、2、3 三条学习线，并按模块推进。课程线、起始模块和最终考试由语言学校根据教育背景、识字情况与学习条件评估，不宜把所有学习线简单对应为同一段 CEFR 范围。

\begin{itemize}
    \item PD3 或其他语言考试是否满足工作、永久居留或入学要求，应按具体岗位、许可类型和申请时点分别核对。
    \item Studieprøven 可作为部分丹麦语授课高等教育项目的语言证明；是否达到入学门槛由具体院校和项目决定。
\end{itemize}

\subsubsection{学习方式}
\begin{itemize}
    \item \textbf{线下固定班：} 在工作日或晚间同固定时段到校上课。
    \item \textbf{混合式（blended learning）：} 每周 1 次线下随班 + 线上自主学习。
    \item \textbf{纯线上：} 全部自选模块、讨论与作业在线完成。
\end{itemize}

\subsubsection{费用与押金政策}
\begin{itemize}
    \item 课程本身 \textbf{免费}。
    \item 首次注册需缴 2 000 DKK \textbf{押金}；按时完成模块并通过测试后，全额退还（或转入下一个模块）。
    \item 长期缺课或未在规定时间内完成模块，押金可能不予退还。
    \item 家庭团聚、au pair 等身份部分市政可免押金，具体以所在市政规定为准。
\end{itemize}

\subsubsection{课程节奏与考试}
\begin{itemize}
    \item 每个模块含定期授课、作业与期末测试；教师根据进度推荐是否参加测试。
    \item 模块测试通过后方可进入下一个模块或报名全国统一考试（PD1/PD2/PD3）。
    \item 对 S-kursist，klippekort 自首次转介起通常有效 5 年，最多包含 6 个 klip，合计相当于 42 个月（3.5 年）的教学额度。每个 klip 有自己的期限；已启动的 klip 通常不会因缺课自动暂停，只有在通过模块测试后、启动下一 klip 前才可按规则安排暂停。
\end{itemize}

\subsubsection{报名流程（通用）}
\begin{enumerate}
    \item 获取 CPR 号并激活 MitID。
    \item 确认居住地市政已经完成丹麦语教育转介；哥本哈根市居民可在市政签约学校中选择，也可按规则选择其他获批准的语言学校。
    \item 联系语言学校完成注册，缴纳适用的押金，并参加分级面谈；课程线和起始模块由学校根据个人教育背景与学习条件评估。
    \item 依据确定的起始模块、班型与上课时间，收到欢迎邮件后按时上课。
\end{enumerate}

\subsubsection{参加资格}
\begin{itemize}
    \item 年满 18 周岁。
    \item 符合官方丹麦语教育范围，并取得居住地市政转介。
    \item S-kursist 的 klippekort 通常自首次转介起有效 5 年；个别延期或转介情形由市政按规定处理。
    \item 不要求入学前具备丹麦语基础。
\end{itemize}

哥本哈根市课程、押金与学校信息：\href{https://international.kk.dk/live/learn-danish/danish-language-courses/danish-language-education-programme}{哥本哈根市官方说明}

\subsection{如何选择语言学校和班型}

语言学校、校区、开课日期和线上/线下安排会随市镇合同和学期调整，不建议按往年课表选课。收到市镇转介后，可按以下顺序比较：

\begin{enumerate}
    \item 查看转介信上的课程权利起算日、报名期限和负责市镇，不要把学校广告当作市镇已经转介。
    \item 确认所选学校能够接收本人市镇的转介，并询问分级、押金、候补、转校及退课规则。
    \item 按真实通勤时间比较日间、晚间、混合式和纯线上班；同时考虑考试周、实习和兼职排班。
    \item 报名前索取当期书面课表。已启动模块后缺课通常不会自动暂停模块期限，如需暂停应先向学校和市镇确认。
\end{enumerate}

\begin{grayleftbox}
\textbf{对中国籍非欧盟学生尤其重要：}取得 CPR 不等于已经完成丹麦语课程转介。若迟迟未收到转介信、搬到其他市镇或准备长期离丹，应先联系居住地市镇和语言学校，确认课程权利、押金和模块期限如何处理。
\end{grayleftbox}

常见语言学校包括 Speak、UCplus、Clavis 等，但其校区和班型并非固定推荐。请从居住地市镇的官方课程页面确认当期获批学校，再访问服务商官网核对实时安排：\href{https://speakspeak.dk}{Speak}、\href{https://ucplus.dk}{UCplus}、\href{https://clavis.org}{Clavis}。学校如另有校内丹麦语课程，应向本校 International Office 确认其是否属于官方 Danskuddannelse、是否计学分以及是否使用市镇转介。
