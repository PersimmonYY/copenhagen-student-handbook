\subsection{求职实习基本信息}

\begin{enumerate}[leftmargin=2em,label=\arabic*.]
  \item \textbf{在丹实习（实训）}\\
        课程内的 mandatory internship 可能无薪；但许多企业实习（特别是工程/IT Student Assistant）会按合同支付时薪。
  \item \textbf{境外实习 / 工作}\\
        需申请目标国实习签；长期离境可能 \textbf{注销丹麦居住身份}。
  \item \textbf{用工顺序}\\
        丹麦法律无硬性“排位”，但雇主在招聘非 EU 人才前，需确保满足工资/工时等额外要求，故实际操作上先用本国 \& EU 员工更便利。
  \item \textbf{找工作前置}\\
        必须拥有 \textbf{住址 → CPR → 丹麦银行账户} 才能签约工资。
\end{enumerate}

\subsection{求职工具与技巧}

\subsubsection{CV 编写}
\begin{itemize}[leftmargin=1.5em]
  \item \textbf{开头}：联系方式 + 1–2 句与 JD 高度相关的个人简介。
  \item \textbf{照片}：丹麦雇主普遍接受简洁职业照。
  \item \textbf{精准投递}：避免海投，结合岗位关键字定制内容。
\end{itemize}

\subsubsection{面试注意点}
\begin{itemize}[leftmargin=1.5em]
  \item \textbf{肢体语言}：微笑、眼神交流。
  \item \textbf{细节}：手机静音、提前踩点。
  \item \textbf{Follow-up}：面试后可视公司文化发送简短感谢邮件（Dear + 名/姓）。
\end{itemize}

\begin{grayleftbox}\textbf{小贴士：}
公司岗位已满时，主动 \textit{speculative application} 也可能获得机会。多数人无法「一次面试即拿 offer」，可先接受过渡岗位，再继续冲击 dream job。
\end{grayleftbox}

\paragraph{两步申请： }
\begin{enumerate}[leftmargin=1.5em,label=\arabic*.]
  \item 先拿实习 Offer：UN Careers (\url{https://careers.un.org}) 或 CSC 岗位清单投递 → 面试 → Offer。
  \item 向 CSC 申请资助：登陆平台 （\url{https://sa.csc.edu.cn/student}） → 选择“国际组织实习项目” → 上传 Offer、CV、英语成绩、成绩单、推荐信等材料。
\end{enumerate}

  CSC 官网 → 出国留学 → 国际组织实习项目\\

\subsection{小结}

\begin{itemize}
  \item \textbf{量力而行}：课程压力大时谨慎接兼职；丹麦生活费虽高，但时间成本同样宝贵。
  \item \textbf{合法合规}：严格遵守 90 h / 全职 规则，超时将影响续签。
  \item \textbf{语言加分}：即便基础岗位，掌握基础丹麦语也能拓宽选择。
  \item \textbf{聚焦简历}：精准对应 JD，适当附照片，避免千篇一律。
\end{itemize}
