\subsection{行李、海关与检疫}

从中国入境属于从欧盟以外地区入境。自用、托运或亲友邮寄并不当然免除海关、食品、药品或动植物检疫规则。

\begin{itemize}[leftmargin=2em,itemsep=3pt]
  \item \textbf{食品：}许多含肉、奶或其他动物成分的食品从非欧盟国家进入欧盟受到严格限制；不要只按包装是否密封或是否为自用判断。
  \item \textbf{药品：}按第~\ref{sec:health}~节逐项检查有效成分、数量和证明；不要让亲友随后直接邮寄抗生素或受控药物。
  \item \textbf{现金与等同工具：}携带总值达到 10,000 欧元的现金或其他受规则约束的流动资金工具入境、出境或过境时，应按丹麦海关要求申报。
  \item \textbf{高价值物品和购物：}保存电脑、相机等贵重物品的购买凭证；搬家物品、超出免税额度的商品及酒烟另有规则。
  \item \textbf{拿不准就申报：}抵达时向海关红色通道或官方客服询问，不要依赖社交平台清单。
\end{itemize}

官方入口：丹麦海关旅行规则 \url{https://toldst.dk/en-us/individuals/travel}；丹麦食品管理局个人携带食品说明 \url{https://foedevarestyrelsen.dk/kost-og-foedevarer/alt-om-mad/privat-indfoersel}。

\subsection{设备、衣物与第一晚准备}

\begin{itemize}[leftmargin=2em,itemsep=3pt]
  \item 丹麦使用 230V/50Hz 供电。核对电脑、手机等充电器铭牌是否支持；携带合格的欧式/丹麦适配器，不使用松动或超负荷转换插头。
  \item 防水外套、适合步行的鞋和分层保暖衣物通常比单件厚重服装更实用；冬装也可抵丹后按实际通勤方式补齐。
  \item 随身携带一晚换洗衣物、基本洗漱用品、必要药品、充电线和充电宝；遵守航司对锂电池和液体的要求。
  \item 提前下载离线地图，保存住宿地址的丹麦文写法，并准备机场到住处的有效车票方案。
  \item 保留中国手机号以接收国内银行、学校或账户验证信息前，先向运营商核对漫游、停机保号和境外收短信条件。
\end{itemize}

\subsection{抵丹后 72 小时最小清单}

\begin{itemize}[label=$\bigcirc$,leftmargin=2.2em,itemsep=3pt]
  \item 已安全入住、检查钥匙和基本设施，并把姓名或约定 c/o 标在信箱上
  \item 已向家人报平安，保存 112、保险、住宿方和学校紧急联系方式
  \item 已检查学生邮箱、报到和迎新安排；知道最近的食品店、药房与公共交通站点
  \item 已拍摄入住状况和表计，不把缺陷报告拖到第 14 天最后一刻
  \item 已按第~\ref{sec:arrival30}~节安排 CPR、MitID、Digital Post、银行和税卡，而不是同时重复提交申请
\end{itemize}
