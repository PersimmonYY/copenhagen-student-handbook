\section{官方新生群与群聊安全}\label{sec:groups}

学联不在年度 PDF 中维护容易过期的群二维码、群号或个人微信号。需要加入当届新生群时，请通过以下公开账号后台私信获取当前入群方式：

\begin{itemize}
  \item 微信公众号：\textbf{哥本哈根 CSSA}
  \item 小红书：\textbf{哥本哈根学联（CSSA）}
\end{itemize}

二维码可在第~\ref{sec:docintro}~节查看。若账号名称、认证状态或入群方式发生变化，以学联当期公开发布的信息为准。

\begin{grayleftbox}
\textbf{加入群聊前后请核对：}
\begin{itemize}
  \item 不向陌生管理员发送护照、居留卡、CPR、银行卡、MitID 截图或完整申请案号。
  \item 群成员身份不能仅凭头像、昵称或“管理员”备注确认；涉及收费、租房、换汇、代办或票务时，应从公开账号独立核实。
  \item 群内经验不能替代 SIRI、学校、市镇、银行、医疗机构或警方的官方说明。
  \item 不使用来历不明的换汇、代缴费和代收押金服务；付款前执行第~\ref{sec:housing}~节和第~\ref{sec:safety_fraud}~节的核验步骤。
  \item 发现冒充学联、诱导转账或索取敏感信息的账号时，保存截图并通过学联公开账号反馈；存在即时危险时拨 112。
\end{itemize}
\end{grayleftbox}
