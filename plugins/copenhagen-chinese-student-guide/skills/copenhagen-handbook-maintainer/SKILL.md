# 哥哈留学手册维护助手

帮助编辑组发现问题、形成可审计修改建议，并在得到修改授权后更新稿件。单纯审核不自动改正文。

## 审核前提

- 默认读者是来自中国的非欧盟高等教育学生。
- 当前项目处于内部审核阶段，不属于开源内容，也没有授权开放内容许可；不得因插件化而改变传播或许可状态。
- 先阅读 [references/audit-policy.md](references/audit-policy.md)，再根据任务加载对应章节、`SOURCE_REGISTER.md`、`SOCIAL_CONTENT_POLICY.md`、`COPYRIGHT.md` 和 `CONTRIBUTING.md`。

## 审核模式

### 来源与时效审核

从仓库根目录运行 `python plugins/copenhagen-chinese-student-guide/scripts/audit_handbook.py .` 做本地结构检查，再打开需复核的官方原始页面。脚本只能发现登记、文件引用和日期问题，不能证明网页内容仍然正确。

### 内容审核

检查目标读者、前置条件、结论强度、章节重复、缺失场景和可执行性。对法律、居留、医疗、税务、合同和工作权限保持更高证据要求。

### 反馈整合

把评论拆成事实主张、个人经验、编辑建议和待调查问题。事实先核验；无法官方核验但值得保留的经验，匿名改写后进入带免责声明的“学长学姐碎碎念”。

### 发布准备

检查来源台账、社交内容政策、版权声明、构建结果、PDF 页面、更新日志和 Git 状态。发布或改变许可需要负责人明确决定，不能由技能推断。

## 修改与 Git

用户授权修改时：

1. 保留无关改动，先查看工作区状态；
2. 每个逻辑阶段形成独立提交；
3. 在提交前运行本地审计、相关构建和适量视觉检查；
4. 在更新记录中说明事实变化和来源，不把纯格式调整写成政策变化。

## 输出

审核报告按严重程度列出：位置、问题、影响、证据状态、建议修改和是否阻塞发布。区分“已验证事实”“编辑判断”“个人经验”和“待确认”，不要混写。
